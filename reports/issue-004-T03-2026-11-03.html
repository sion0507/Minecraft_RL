1. 수락 기준과 구현

기준구현·확인 근거
제한 관측과 기억눈에서 반경 8블록 안 셀 중심으로 광선을 보내 첫 충돌/위험 표면에서 끊는다. 통과한 공기·비충돌 식물과 노출 표면, 자기 상태·방향·도구·지도 버전·방문·최근 결과만 출력한다. reset은 기억을 비운다.
같은 지도에 근거한 이동Python BFS는 관측된 동일 높이의 바닥·발/머리 공간만 연결한다. 후보 최대 8개·경로 16블록·400 활성 틱. Node는 같은 공개 셀로 경로와 위험/변경/정체·안정 경계를 판단한다.
실제 숨은 정보 불변관리자 전용 장면 준비 후 정책 observe/step으로 벽 뒤 광석/용암 두 경우를 비교한다. run ID와 벽시계만 제외하고 관측·후보·경로·실행/중단 결과가 같아야 한다. 벽을 연 양성 대조도 포함해 실제 통과했다.
실행과 근거 공개moved/stopped 사건, 원본 관측 ID, 최종 지도 버전, 경로, 중단 근거·이유, 실제 틱·이동 거리·경과 시간·정지 인증·안정 경계를 JSONL에 저장한다. hidden_hazard_peek=false.
감사 범위 구분이번 범위는 관측과 같은 높이의 보행이다. 제작·계단 하강·터널의 정보 감사는 각 담당 티켓과 최종 lock 전에 추가한다.

2. 코드 연결

bridge/terrain.js: 시야·지도·보행 전제조건·위험/안정 판정.
bridge/minecraft.js: 실제 이동·틱 제한·관리자 정보 fixture.
navigation.py / information.py: 공개 지도 후보와 실제 감사.
schema.py / episode.py / cli.py: 기존 RPC/실행 흐름·요약 확장.

새 의존성·모델·학습·유료 API를 추가하지 않았다. 이동 후보는 현재 진단용 고정 첫 선택이며 NanoJev/S 선택기의 성능 검증이 아니다.

4. 실패와 수정

  • 첫 sandbox 실행은 서버 소유권 확보 실패. 권한을 허용한 실제 서버 실행으로 재검증했다.
  • 풀을 가리개로 취급해 발밑 지면이 누락됐다. 실제 공개 관측에서 원인을 확인하고 비충돌 식물을 통과하도록 수정했다.
  • 접지 중 남는 중력 속도를 이동으로 오인해 안정화가 끝나지 않았고 timeout이 발생했다. 실제 기존 속도·설치 물리 코드와 RED→GREEN 검사로 판정을 고쳤다. 실패 시도도 보존했다.
  • 독립 검토에서 3축 광선 모서리 누출을 재현하고 첫 차단 즉시 중단으로 고쳤다. 이동 smoke의 허위 성공과 죽은 플레이어의 physicsTick 대기도 보완했다.

5. 제한·미실행·근거

유리/부분 충돌 블록을 보수적으로 가리므로 모든 실제 가시 표면을 복원하는 관측기는 아니다. 일반 높이 차·점프·채굴·제작·계단·터널, 모델 추론·PPO·전체 C4/G4 평가·온라인 계정 인증은 미실행이다. 이번 장면은 관리자 제작 진단이며 자연 다이아 성공이나 새로운 월드 일반화를 주장하지 않는다.
