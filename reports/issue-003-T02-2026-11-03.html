1. 이번 범위와 연결 구조

4. 핵심 결함: 시간이 멈춰도 플레이어는 진행

Carpet freeze와 physicsEnabled=false만 적용한 침수 5초 시험에서 게임 틱은 같았지만 산소 Air가 281 → 172로 줄었습니다. 요청 성공이나 게임 시간 정지만으로 정지를 인정할 수 없음을 실제로 확인했습니다.

7. 코드 검토와 오류 처리 보완

발견한 문제수정과 확인
reset 간 관측 ID 재사용매 reset에 새 UUID. 실제 이전 후보는 invalid_selection으로 거부하고 틱을 소비하지 않음.
Java 정리 전 bridge 강제 종료진행 작업 중단, 종료 유예 2→15초, flock 커널 잠금. 느린 종료 회귀 검사와 실제 잠금 해제 확인.
끊긴 bot의 cached 관측end/error 이후 관측·행동 거부. 실제 Java 자식 종료 후 backend_error 확인.
snapshot 루트 symlink 우회루트/상위 디렉터리와 hash를 교체 전 검사. 공개 회귀 검사에서 현재 월드 보존 확인.
드롭 콘솔 timestamp 오비교로그 문자열 대신 추출한 NBT 비교. 실제 지연 시험에서 같은 드롭 상태 확인.
마지막 틱 실패의 종료 표시 중복지원된 실행에만 truncation 적용. 실제 미지원 실패 1틱·invalid 단독 결과 확인. 전체 36,000틱 경계는 미실행.

읽기 전용 독립 검토 1회 후 작성자가 수정·검증했습니다. 수정 뒤 별도 재검토는 하지 않았습니다. 개발 검사는 pytest 27개 통과, strict mypy 12개 파일 통과입니다. mock/scripted RPC 검사와 실제 물리 시험을 구분했습니다.
