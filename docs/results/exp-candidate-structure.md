# 후보 구조·시간 비용 실험 결과 (브랜치 exp/candidate-structure, 2026-11-12 ~ 11-14)

모든 실행은 실제 Minecraft(정지 인증)와 공개 NanoJev를 썼다. mock 결과는 없다. 고정 월드 하나의 결과다. 시간 비용 설정(T)만 학습 시드 2개로 두 번 학습했고 나머지 팔은 학습 1회이며, 새 월드 일반화를 보지 않았다. 원시 trace·head·중간 산출물은 Git에 넣지 않았다(`artifacts/exp/`, 로컬 보존).

## 요약

- **원래 문제:** 돌 단계 결정의 58%가 걷기 후보뿐이라 고를 것이 없었고, 느린 선택도 결국 성공해 선택 간 수익 차이가 없었으며, 후보가 0개이거나 1개만 반복되는 막다른 길이 실패를 만들었다.
- **바꾼 것:** 후보 구조(계단 파기, 목표 쪽 걷기, 접근 후보 축소), 틱당 시간 비용(`pilot_tick_cost`, 1,200틱에 1), 누적 수익 critic 재학습, 막다른 길 5건 수정.
- **T (시간 비용, 3,072결정):** 30슬롯 평균 완료 틱 1,558 → 1,205(−22.6%), bootstrap 95% [−646, −42], 부호검정 p=0.004, 성공 30/30 → 29/30. 고정 상태 185개에서 계단 확률 0.41 → 0.73(균등 0.37).
- **T2 (T 재현: 같은 설정, 학습 시드 11016, D3와 같은 코드):** 30슬롯 평균 1,558 → 952(−38.9%), bootstrap 95% [−882, −348], 부호검정 p<0.001(25 단축·4 느림·1 동률), 성공 30/30. 계단 확률 0.41 → 0.82. D3 대비 −35.4%, 95% [−751, −312]. **T의 정책 변화와 시간 단축이 다른 학습 시드에서 재현됐다**(14절).
- **D3 (시간 비용 없음, 3,072결정, T와 같은 시드):** 30슬롯 −5.3%, 95% [−331, +165]로 미학습과 차이 없음. 계단 확률 0.405. 학습 기록의 수익 차이(계단 − 탐색)는 T 0.24, D3 0.00.
- **철 과제(학습에 안 쓴 과제, 10슬롯):** 1/10 → 4/10(Fisher p≈0.30, 개선을 주장할 수준은 아님). 실패는 곡괭이 소진과 캘 자리에 못 가는 구조 문제(#54 범위).
- **critic 입력 비교(오프라인):** 효과가 재현된 입력은 보유량과 단계. 바라보는 방향 각도·보임 여부·거리는 추가 효과 미확인. 신경망 critic은 학습 내내 단계별 평균 수준을 못 넘었고, 단계×보유량×상황 27칸 표가 숫자 입력 신경망과 같은 수준.
- **사전 등록 기준(3절) 판정:** T는 (1)(2)(3) 통과. T2는 (1)(2) 통과, (3) 철 과제는 T2 head로 실행하지 않았다.

## 미검증·미실행

- **T2 head의 철 과제 평가:** 미실행. 철 과제 수치(1/10 → 4/10)는 T head 1회의 것이다.
- **T2가 T보다 더 빨라진 이유(952 대 1,205틱):** 분리하지 못했다. T2는 학습 시드와 코드(막다른 길 수정 3건 추가)가 함께 다르다. 시간 비용의 효과를 보는 깨끗한 비교는 같은 코드의 T2 대 D3이며, 이 둘도 학습 시드는 다르다(11016 대 11015).
- 시간 비용 설정의 학습은 시드 2개다. 시간 비용 없는 쪽(D3)은 3,072결정 학습 1회다.
- **M(돌곡괭이+철 혼합 학습):** 사용자 결정으로 #54 해결 뒤로 미룸.
- **critic을 표 기준값으로 바꾼 학습:** 별도 이슈에서 진행.
- 계단 후보 수 제한 변형(`--stone-stairs`), critic 재학습을 끈 대조군: 미실행.
- 10슬롯 비교는 잡음이 크다(D3는 정책이 균등인데도 처음 10슬롯에서 −17%). 철 과제 판정이 이 한계를 갖는다.
- T·D는 커밋 3a52353, D3·T2는 막다른 길 수정이 더 들어간 70212f4 이후 코드로 실행했다.
