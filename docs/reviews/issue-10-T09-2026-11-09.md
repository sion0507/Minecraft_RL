# #10 T09 두 축 코드 리뷰

기준: 작업 시작 main `7a7f8c875f469a92a3803f356bcb9db10b112c5f`부터 이번 구현의 tracked diff와 신규 파일 전체. 코드/설정/출처/README/계획과 실행 원시를 독립 읽기 전용 Standards/Spec 에이전트가 검토했다. 리뷰 자체는 GPU·게임·유료 API를 실행하지 않았다. 실제 Astra 승인 대기는 구현 결함과 구분했다.

## Standards

최초 지적 **2건**:

1. P1: `AstraPlanner.__call__`에서 응답 비용이 예약 상한을 넘으면 작은 예약액만 남아 재실행으로 비용을 더 쓸 수 있다. AGENTS의 비용 상한/실패 비용 보존 계약 위반이다.
2. P2: `LocalPlanner.__call__`의 CUDA OOM 등 RuntimeError가 공통 오류/요약 경계를 벗어나 실패 지연과 summary를 남기지 않는다. AGENTS의 실패 기록·공개 실행 계약 위반이다.

## Spec

최초 지적 **3건**:

1. P1: 비용 상한 위반 이후 호출이 계속 가능해 #10의 “호출/금액 상한”을 지키지 못한다(Standards1과 중복).
2. P2: HTTPError는 URLError의 하위라400/422 요청/지원 옵션 오류도 접근 불가로 처리된다. #10의 “외부 접근 불가, 예산/승인 대기, 구현 오류를 구분” 계약 위반이다.
3. P2: CUDA 추론 실패가 traceback으로 끝나 #10의 “설치/실행 실패를 기록” 계약을 충족하지 못한다(Standards2와 중복).

## 수정·검증

- 비용 위반: `record_cost`가 확인한 요율 기반 비용을 영속 저장하고 해당 ledger를 blocked로 고정한다. 재생성·다른 adapter 인스턴스/프로세스에서도 reserve가 후속 요청을 거부한다. 예약은 자동 환불하지 않는다. 제공처가 승인 시 검증한 요청당 최악 비용을 어기는 첫 요청 자체를 로컬에서 사전 방지한다고 주장하지 않는다.
- HTTP: HTTPError를 먼저 잡고 안전한 status만 기록한다.400/422등은 planner_error/request_error,401/402/403/404/408/429/5xx는 planner_unavailable/access_unavailable이다. 원본 에러 문자열/응답은 로그로 내보내지 않는다.
- 로컬: generate/decode RuntimeError/ValueError/OSError를 안전한 planner_error로 바꾸고 실패 planner_call·지연과 기존 EpisodeSummary를 보존한다. 규칙 복구로 모델 실패를 숨기지 않는다.
- `artifacts/issue-10/review-red.txt`: 위 세 경로 **3failed** 재현. `review-green.txt`: **17passed**. 기본 pilot 명령 보완까지 포함한 최종 `pytest-final.txt`: **229passed /69.51초**, `mypy-final.txt`: **31파일 통과**, `git diff --check` 통과.
- 수정 뒤 독립 재리뷰는 하지 않았다. 각 지적의 실패→통과와 최종 전체 검사로 수정 근거를 남겼다. 최종 잔여로 결정한 지적/보류한 minor는 없다. 이는 모든 결함이 없다는 보장은 아니다.
- 최종 문서 명령 확인에서 planner 설정이 없는 `configs/pilot.yaml` 기본 명령도 지원하도록 local_7b 기본값을 적용했다. 별도 CLI 회귀는 `pilot-command-red.txt`의 실패를 재현한 뒤 `planner-final.txt` **18passed**로 통과했다. 이후 전체 검사를 다시 수행했다. 명시적 planner 설정의 실제 Qwen/G1 경로와 다른 명령의 고정 목표는 바꾸지 않았다.

실제 Qwen+자연 G1 성공5결정216틱과 기준 복원 원시도 확인했다. Astra의 실제 계정/버전·지원 옵션·사용량/과금·호출 지연은 승인/계정 설정 대기로 미검증이다. Jev 연결#12,6상태 비교#17,예산/lock#20과 실제 전체 평가는 후속 책임을 유지한다.
