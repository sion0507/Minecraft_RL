# T04 관측 원목 수집 구현 계획

**Goal:** GitHub #5의 목재 접근·장착·노출 군집 채굴·드롭 획득을 공개 smoke-macros에 연결한다.
**Spec:** GitHub #1 본문·댓글(없음), #5 본문·댓글(없음), PLAN §§4.1–4.3, 5.2, 5.4, 12–14.
**Architecture:** 기존 Python 후보/episode와 Node 제한 관측·이동·정지 실행기를 확장한다. 모델 없이 첫 유효 후보를 선택하는 진단이며 actor 전이는 0이다. 현재 깨끗한 main의 기준 e604936에서 작업하고 implement 지시에 따라 현재 브랜치에 커밋한다.

## 공통 제약과 검토 초점

- 최대 8후보, 이동 16블록/400틱, 선택한 노출 군집 8블록/400틱, wait 20/100/200틱.
- 숨은 정보·관리자 정보를 판단에 사용하지 않는다. 후보 ID/내용/순서/mask와 근거 obs/map을 보존한다.
- 단일 후보 확률 1, 0후보 실제 wait와 실패, 무효 선택 취소의 시간/사건 한 번 집계·actor 제외·trace 단절.
- Mineflayer 벽시계 dig 완료 대신 활성 틱으로 파괴 요청을 진행하며 실제 드롭/인벤토리로 획득을 확인한다.
- 위험·파손·실패·시간·사망 및 reset의 공개 결과를 검사한다. 실제 fixture는 자연 성공과 구분한다.
