- B offers at most one cut toward a visible target within eight blocks, only when no walking approach exists. Preserve a walk alongside it; log target, walking availability and actual digging ticks.
- C1 keeps representative directions/workloads; C2 changes the choice interface and C3 breaks group parity, so neither is used.
- D keeps four-stair/400-tick limits and highlights continuation. User's ExRL reference is applied as 1/4 workload choices, explicit stone-based tick estimates, state-wise length histograms and same-seed fixed4 evaluation controls. No learning-code change or automatic multi-macro chain.
- E recovers reachable crafting tables as an explicit mining candidate before descending; empty, observed furnaces may use the same rule. Never recover an active/uninspected furnace.
- F1 permits two-/three-block drops only with an observed clear column and safe landing. F2/F5 describe/select deep, resource-facing and frontier exploration endpoints. F4 applies to all digging.
- User approved: walk/tunnel/down/up/other slots 6/4/3/2/1; dirt-first, cobblestone reserve; pillar cap four; A4/F3 deferred.
